# Глоссарий

## Термины проекта

### A

**Augmentation** - Аугментация данных, техника увеличения разнообразия обучающих данных путем применения преобразований (поворот, масштабирование, шум и т.д.)

**Attention Mechanism** - Механизм внимания, позволяет модели фокусироваться на важных частях последовательности

### B

**BiGRU** - Bidirectional GRU, двунаправленная GRU сеть, обрабатывающая последовательность в обоих направлениях

**Blob Storage** - Облачное хранилище для файлов (в данном проекте - Vercel Blob Storage для моделей)

### C

**Canvas** - HTML5 Canvas элемент, используемый для рисования подписей в браузере

**Checkpoint** - Сохраненное состояние модели во время обучения, включает веса и метаданные

**CNN** - Convolutional Neural Network, сверточная нейронная сеть для извлечения признаков

**Cosine Similarity** - Косинусное сходство, метрика для сравнения векторов (эмбеддингов)

### D

**Dataset** - Датасет, набор данных для обучения модели

**Downtime** - Время простоя сервиса, когда он недоступен

### E

**EER** - Equal Error Rate, равная частота ошибок, метрика качества модели верификации

**Embedding** - Эмбеддинг, векторное представление подписи в многомерном пространстве

**Epoch** - Эпоха, один полный проход по всему обучающему датасету

### F

**FastAPI** - Современный веб-фramework для Python, используемый для inference сервера

**Forgery** - Подделка, поддельная подпись

**Frontend** - Клиентская часть приложения, пользовательский интерфейс

### G

**Genuine Signature** - Подлинная подпись, оригинальная подпись пользователя

**GRU** - Gated Recurrent Unit, тип рекуррентной нейронной сети

### H

**Hotswap** - Горячая замена, переключение моделей без перезапуска сервера

### I

**Inference** - Вывод, процесс использования обученной модели для предсказаний

**Input Type** - Тип ввода, способ создания подписи (mouse, touch, pen)

### J

**JWT** - JSON Web Token, токен для аутентификации и авторизации

### L

**LMDB** - Lightning Memory-Mapped Database, формат хранения данных для эффективной загрузки

**Loss Function** - Функция потерь, метрика для оценки качества модели во время обучения

### M

**Model** - Модель, обученная нейронная сеть для верификации подписей

**Model Manager** - Менеджер моделей, система управления загрузкой и переключением моделей

**Moderator** - Модератор, роль пользователя с расширенными правами

### N

**Next.js** - React framework для создания веб-приложений

### P

**PK Sampling** - Стратегия выборки данных: P пользователей, K подписей от каждого

**Preprocessing** - Предобработка, преобразование сырых данных в формат для модели

**Profile** - Профиль, информация о пользователе в системе

**Pseudouser** - Псевдопользователь, виртуальный пользователь для внешних данных

### R

**RLS** - Row Level Security, безопасность на уровне строк в базе данных

**Role** - Роль, уровень доступа пользователя (user, mod, admin)

### S

**Serverless** - Бессерверная архитектура, выполнение кода без управления серверами

**Signature** - Подпись, цифровая подпись пользователя

**Similarity Score** - Оценка схожести, числовая метрика схожести двух подписей (0-1)

**Supabase** - Backend-as-a-Service платформа, используемая для БД и аутентификации

### T

**Threshold** - Порог, значение для определения подделки/подлинности

**Training** - Обучение, процесс обучения нейронной сети на данных

**Triplet Loss** - Триплетная функция потерь, используемая для обучения модели

### U

**User** - Пользователь, обычный пользователь системы

### V

**Vercel** - Платформа для развертывания frontend и serverless функций

**Verification** - Верификация, процесс проверки подлинности подписи

### W

**Weights** - Веса, параметры нейронной сети, которые обучаются во время training

## Дополнительные термины

**Zero Downtime** - Нулевое время простоя, переключение без прерывания обслуживания

**Sequential Swap** - Последовательная замена, переключение с временным прерыванием

**Service Role** - Роль сервиса, полный доступ к данным для backend операций
