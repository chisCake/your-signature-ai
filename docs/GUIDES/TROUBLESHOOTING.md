# Решение проблем

## Обзор

Это руководство поможет решить типичные проблемы, возникающие при работе с Your Sign AI.

## Frontend проблемы

### Проблема: Не загружается страница

**Симптомы**: Белый экран или ошибка загрузки

**Решения**:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что переменные окружения настроены
3. Проверьте подключение к Supabase
4. Очистите кэш браузера

### Проблема: Ошибки аутентификации

**Симптомы**: Не удается войти или зарегистрироваться

**Решения**:
1. Проверьте настройки Supabase Auth
2. Убедитесь, что redirect URLs настроены правильно
3. Проверьте JWT токены в консоли
4. Очистите cookies и попробуйте снова

### Проблема: Canvas не работает

**Симптомы**: Нельзя рисовать на canvas

**Решения**:
1. Проверьте поддержку Pointer Events в браузере
2. Убедитесь, что canvas элемент инициализирован
3. Проверьте консоль на ошибки JavaScript
4. Попробуйте другой браузер

## Backend проблемы

### Проблема: Модель не загружается

**Симптомы**: Ошибка при загрузке модели или `/health` возвращает `model_loaded: false`

**Решения**:
1. Проверьте наличие файлов `.pt` и `.py` в `models/`
2. Убедитесь, что файлы совместимы
3. Проверьте логи inference сервера
4. Убедитесь, что модель экспортирована правильно

### Проблема: Ошибки inference

**Симптомы**: Ошибки при верификации подписей

**Решения**:
1. Проверьте формат входных данных
2. Убедитесь, что предобработка работает правильно
3. Проверьте размеры тензоров
4. Посмотрите логи для деталей ошибки

### Проблема: Медленный ответ

**Симптомы**: Долгое время ответа от API

**Решения**:
1. Проверьте размер модели
2. Используйте более быстрый device (GPU если доступно)
3. Оптимизируйте предобработку
4. Проверьте сетевую задержку

## Database проблемы

### Проблема: Не удается подключиться к Supabase

**Симптомы**: Ошибки подключения к БД

**Решения**:
1. Проверьте URL и ключи в `.env`
2. Убедитесь, что Supabase проект активен
3. Проверьте настройки сети/firewall
4. Проверьте статус Supabase на status.supabase.com

### Проблема: RLS блокирует запросы

**Симптомы**: Ошибки доступа к данным

**Решения**:
1. Проверьте RLS политики в Supabase Dashboard
2. Убедитесь, что пользователь аутентифицирован
3. Проверьте роль пользователя
4. Используйте service role для backend операций

## Training проблемы

### Проблема: Не загружаются данные

**Симптомы**: Ошибки при загрузке подписей из Supabase

**Решения**:
1. Проверьте credentials в Colab Secrets
2. Убедитесь, что подписи помечены `mod_for_dataset=true`
3. Проверьте подключение к Supabase
4. Проверьте фильтры по типу ввода

### Проблема: Ошибки при обучении

**Симптомы**: Ошибки во время обучения модели

**Решения**:
1. Проверьте размер датасета
2. Убедитесь, что данные правильно предобработаны
3. Проверьте конфигурацию модели
4. Уменьшите batch size если не хватает памяти

## Общие проблемы

### Проблема: CORS ошибки

**Симптомы**: CORS ошибки в консоли браузера

**Решения**:
1. Проверьте настройки CORS в inference сервере
2. Убедитесь, что `FRONTEND_URL` настроен правильно
3. Добавьте домен в разрешенные origins

### Проблема: Переменные окружения не работают

**Симптомы**: Значения переменных окружения не применяются

**Решения**:
1. Убедитесь, что файл `.env` находится в правильной директории
2. Перезапустите сервер после изменения `.env`
3. Проверьте синтаксис `.env` файла
4. Для Next.js используйте `NEXT_PUBLIC_` префикс для публичных переменных

## Логи и отладка

### Frontend логи

Откройте DevTools (F12) и проверьте:
- Console - JavaScript ошибки
- Network - Запросы к API
- Application - Cookies и Local Storage

### Backend логи

Проверьте логи inference сервера:
- В консоли при локальном запуске
- В Vercel Dashboard для production

### Database логи

В Supabase Dashboard:
- Logs → Postgres Logs
- Logs → API Logs

## Производительность

### Медленная загрузка страниц

**Решения**:
1. Оптимизируйте изображения
2. Используйте code splitting
3. Кэшируйте данные где возможно
4. Проверьте размер bundle

### Медленный inference

**Решения**:
1. Используйте GPU если доступно
2. Оптимизируйте размер модели
3. Используйте batch processing
4. Кэшируйте эмбеддинги
